# 字幕助手 1.0.0.10

本次稳定版修复了 Emby 取消迅雷字幕搜索时产生的错误日志问题。关闭搜索面板、
重复发起搜索、网络断开或停止计划任务时，不再误记录 `SubtitleManager` 错误。

- 调用方取消搜索时，现在返回空结果，不再把 `OperationCanceledException`
  传给 Emby 的全局异常日志记录器。
- 多个调用方共享的迅雷搜索任务仍与单个调用方解耦，某个调用方取消后，任务
  会继续为其余调用方执行完成。
- 搜索开始前已经取消的请求会立即返回，不再发起网络请求。
- 超时、HTTP、代理和异常响应的处理逻辑保持不变。
