# Subtitle Assistant 1.0.0.10

This stable release removes false `SubtitleManager` error entries when Emby cancels
a Thunder subtitle search because the user closes the search panel, repeats the
search, disconnects, or stops a scheduled operation.

- Caller cancellation now returns an empty provider result instead of propagating
  `OperationCanceledException` through Emby's all-exception error logger.
- Thunder work shared by concurrent callers is still detached from any one caller
  and continues to complete for the remaining callers.
- Pre-cancelled searches return immediately without starting network traffic.
- Timeout, HTTP, proxy, and malformed-response handling are unchanged.
