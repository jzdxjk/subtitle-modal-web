# 字幕助手 1.0.0.11

本次稳定版恢复独立的“海南鸡字幕”下载器。它直接读取 16 分片 Cloudflare
静态字幕库，不再逐次搜索和下载调用旧动态公共池。

## 主要更新

- 通过 `directory.json` 定位 16 个静态分片，按番号查询分片索引。
- 只接受内容寻址字幕路径，并在下载后校验索引声明的 SHA-256。
- 静态未命中时返回空结果，由 Emby 继续查询后续已启用来源。
- 新增“海南鸡字幕”设置页、请求超时、展示上限和独立代理开关。
- 手动搜索默认顺序为海南鸡、本地、迅雷，可在全局设置中调整。
- 新入库自动补全可启用海南鸡来源；历史补全仍只使用本地和迅雷来源。
- 迁移版本提升到 3，恢复旧海南鸡来源设置；没有明确选择过的媒体库默认
  关闭海南鸡来源，避免升级后自动改变行为。
- 保留 `1.0.0.10` 的迅雷搜索取消修复，不再产生误报的
  `SubtitleManager` 错误日志。
