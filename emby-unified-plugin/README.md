# 字幕助手

一个 Emby 插件，提供本地字幕、迅雷字幕、海南鸡字幕三个原生字幕下载器，并保留字幕云的生成、任务查看与完成后刷新功能。安装文件只有 `Emby.SubtitleAssistant.dll`，无需附带 Emby SDK 或外部别名表。

详情页包含本地字幕、迅雷字幕、海南鸡字幕、字幕云、全局设置五个标签。新入库自动补全开关位于“全局设置”；中文字幕语言标记固定为 `zh-CN` / `zh-TW`，不提供自定义。三个下载器分别提供最大展示数量设置，默认各5条；此设置在完整搜索、匹配、去重和排序之后应用，不减少本插件自动补全可用的候选。

## 番号与排序

搜索只使用文件名中确定的番号，不用标题、演员名或视频哈希兜底。文件名中有多个冲突作品号则不搜索。普通有码统一分隔符，并保留原数字拼写；例如：

```text
SSIS-157-LTX【2021-08-19】（演员名）后续标题.mp4 → 仅查询 SSIS-157
SSIS-157-c-无码破解.mp4 → 仅查询 SSIS-157
```

- FC2任一写法都查询 `FC2-PPV-N`、`FC2PPV-N`、`FC2-N` 三式。
- 素人使用内置映射双向查询，如 `300MIUM-1336`、`MIUM-1336`；未知数字前缀的完整号可派生短号，只有短号时不猜数字。
- 日期式无码同时查询横杠、下划线两式，保留全部数字和前导零，匹配时忽略厂商名。
- HEYZO、Tokyo-Hot N编号分别查询横杠、下划线和紧凑三式。
- CD、Part等分片标记不参与作品匹配，不自动切轴或拼接字幕。

变体结果合并后，每个来源内按视频与字幕时长差从小到大、再按字幕字节数从大到小排序。手动搜索结果的来源先后由本插件“全局设置 → 搜索结果来源顺序”决定（默认海南鸡→本地→迅雷），保存后需重启 Emby 才生效；新入库自动补全仍按各媒体库原生下载器顺序。搜索结果里的文件大小统一按 1024 进制显示为一位小数的 KB。

迅雷优先使用解析出的字幕真实时长并标注“字幕轴”，解析不到时改用接口时长（毫秒换算为秒）并标注“迅雷API”，两者都没有时显示“unknown(迅雷API)”；搜索时获取所有同号候选的实际文件大小，正文缓存24小时、总量128MiB，正式下载优先复用。别名搜索、预取与下载统一使用“迅雷字幕”里的请求超时设置（默认15秒，范围1-120），预取并发4。时长或大小失败会标注未知；大小不能超过更小的时长差。视频时长来自Emby已有元数据，不读取大视频计算哈希。

本地和海南鸡使用实际字幕轴的最大结束时间。支持SRT、ASS、SSA及有界ZIP解包。按Emby请求语言筛选，无法确认语言的同号结果仍保留；中文对照字幕和少量日文人名不会被当作纯日文排除。

## 自动补全及下载命名

新入库处理与“字幕助手：补全缺失中文字幕”原生计划任务共用处理流程：只调用该媒体库启用的三个自家来源，按原生顺序尝试；全禁用则跳过，不调用其他插件。已有中文字幕时跳过，无结果时不自动提交云端生成。

新入库默认等待60秒，全新安装默认关闭，迁移继承原配置。补全计划任务默认没有触发时间，可在Emby计划任务中设置。媒体库的语言、匹配和跳过条件继续生效；番号同号不冒充原生视频哈希“完美匹配”。

下载使用原视频完整stem命名，按Emby规则附加语言及实际扩展名，例如：

```text
SSIS-157-c-无码破解.mp4
SSIS-157-c-无码破解.zh-CN.srt
```

语言标记以实际Emby版本的原生命名结果为准。字幕保存位置遵循媒体库设置。手动下载通过实际文件变化确认写入后刷新；自动补全在原生下载返回成功后刷新。二者只刷新对应视频，刷新时关闭再次字幕下载，不另排全目录扫描。

## 代理与字幕云

支持HTTP代理（含HTTPS CONNECT）和SOCKS5，可填写单独认证字段、局域网绕过和主机通配符。迅雷、海南鸡、字幕云、插件更新可分别选择路由；字幕云及局域网默认直连，本地文件访问仍使用文件系统。代理失败不自动转直连。配置保存后对新请求生效。设置页的测试按钮直接显示本次请求的实际路由（代理/直连）与往返延迟。

字幕云继续连接外部服务，保留STRM类型、音轨提示、路径映射、提交、任务查看和完成回报。配置、云操作、代理测试和更新仅管理员可用；自建设置接口仅返回密钥存在标记，空值保留，显式清除才删除。云端认证请求不跟随重定向，请填写服务的最终地址。

## 安装、迁移与更新

首次启动会校验并迁入原四插件的设置，迁移媒体库旧来源名称和禁用状态。额外 `MeiamSub.Thunder` 不作为迅雷配置基线。迁移前备份，失败回滚；完成标记避免后续重启重新覆盖用户修改。原旧配置不删除。海南鸡字幕池服务地址固定为 `https://chickenrice-subtitle-pool.jzdxjk.workers.dev`，不在设置页提供修改入口，迁移时忽略旧插件的自定义地址。

生产部署使用 `tools/deploy_stage.py`：先确认指定Emby配置挂载，校验已验收DLL的SHA256，备份配置和SQLite一致性快照，再仅移出指定五个旧DLL并原子放入新DLL。脚本不重启Emby；安装后由管理员安排重启。不要将旧DLL继续保留在扫描的plugins目录。

“字幕助手：检查并安装更新”原生任务默认每24小时运行，只接受兼容当前宿主的正式版。下载、校验、备份、替换完成后仅通知待重启；不自动中断播放。设置页不再提供“检查更新”按钮，更新只由该计划任务执行。更新清单地址固定在代码中，不在设置页提供修改入口，默认：

```text
https://github.com/jzdxjk/subtitle-modal-web/releases/download/emby-subtitle-assistant-update/update.json
```

正式版本使用独立标签 `emby-subtitle-assistant-v1.0.0.3`，更新清单指向不可变版本DLL。详见 `Updates/README.md`。

## 构建与验证

```powershell
dotnet test emby-unified-plugin.Tests/Emby.SubtitleAssistant.Tests.csproj -c Release
dotnet build emby-unified-plugin/Emby.SubtitleAssistant.csproj -c Release
```

编译基线为netstandard2.1和SDK4.8.11.0。目标宿主为4.8.11.0、4.9.1.80、4.9.5.0、4.10.0.40、4.10.2.0。自动化测试不代替运行验收；五版官方隔离宿主、实际API/下载/刷新/代理/任务及浏览器交互证据保存在 `validation/reports` 和对应验收报告中。实际部署必须使用该矩阵通过的同一个SHA256。

海南鸡配套接口增加重复 `codes` 参数和 `match=work`；原单号接口、分片精确查询、旧canonical及下载ID继续保留。无需删除或回填旧字幕记录。
