# 字幕助手

一个 Emby 插件，提供本地字幕、迅雷字幕、海南鸡字幕三个原生下载器，并保留字幕云的生成、任务查看与完成后刷新功能。海南鸡字幕从静态目录、番号索引和内容寻址字幕文件读取，不逐请求调用旧动态 Worker。设置页包含本地、迅雷、海南鸡字幕、字幕云、全局设置五个板块。安装文件只有 `Emby.SubtitleAssistant.dll`，无需附带 Emby SDK 或外部别名表。

新入库自动补全开关位于“全局设置”；中文字幕语言标记固定为 `zh-CN` / `zh-TW`，不提供自定义。本地字幕和海南鸡字幕手动结果默认最多展示5条，迅雷字幕默认及上限为10条；展示上限在完整搜索、匹配、去重和排序之后应用，不减少自动补全可用候选。

## 番号与排序

搜索只使用文件名中确定的番号，不用标题、演员名或视频哈希兜底。文件名中有多个冲突作品号则不搜索。普通有码统一分隔符，并保留原数字拼写；例如：

```text
SSIS-157-LTX【2021-08-19】（演员名）后续标题.mp4 → 仅查询 SSIS-157
SSIS-157-c-无码破解.mp4 → 仅查询 SSIS-157
```

- FC2任一写法都查询 `FC2-PPV-N`、`FC2PPV-N`、`FC2-N` 三式。
- 素人使用内置映射双向查询，如 `300MIUM-1336`、`MIUM-1336`；未知数字前缀的完整号可派生短号，只有短号时不猜数字。
- 日期式无码同时查询横杠、下划线两式，保留全部数字和前导零，匹配时忽略厂商名。
- HEYZO、Tokyo-Hot N编号分别查询横杠、下划线和紧凑三式。
- CD、Part等分片标记不参与作品匹配，不自动切轴或拼接字幕。

静态海南鸡字幕按番号索引精确检索，命中下载后校验 SHA-256；静态未命中时由 Emby 继续搜索后续已启用来源。手动来源顺序由“全局设置”调整（默认海南鸡→本地→迅雷），保存后需重启 Emby；自动补全按各媒体库原生下载器开关与顺序执行。迅雷还会按固定上传标记查询海南鸡字幕，符合条件的结果优先于普通迅雷结果；相同内容合并时保留海南鸡名称和主下载地址，并保留普通迅雷地址作候补。Thunder 候选仍须匹配准确番号、请求语言与支持格式；标记查询失败时普通结果继续可用，不从字幕云台账补充未被迅雷收录的条目。所有结果随后按视频与字幕时长差、字幕字节数排序；展示上限不会减少自动补全可用候选。大小以 1024 进制显示为一位小数的 KB。

迅雷优先使用解析出的字幕真实时长并标注“字幕轴”，解析不到时改用接口时长（毫秒换算为秒）并标注“迅雷API”，两者都没有时显示“unknown(迅雷API)”；搜索时获取所有同号候选的实际文件大小，正文缓存24小时、总量128MiB，正式下载优先复用。别名搜索、预取与下载统一使用“迅雷字幕”里的请求超时设置（默认15秒，范围1-120），预取并发4。时长或大小失败会标注未知；大小不能超过更小的时长差。视频时长来自Emby已有元数据，不读取大视频计算哈希。

本地字幕使用实际字幕轴的最大结束时间。支持SRT、ASS、SSA及有界ZIP解包。按Emby请求语言筛选，无法确认语言的同号结果仍保留；中文对照字幕和少量日文人名不会被当作纯日文排除。

## 自动补全及下载命名

新入库处理与“字幕助手：补全缺失中文字幕”原生计划任务共用处理流程：新入库仅调用该媒体库启用的海南鸡、本地与迅雷来源，按原生顺序尝试；海南鸡来源默认按库关闭。历史补全继续使用本地与迅雷来源。全禁用则跳过，不调用其他插件。媒体有任意已识别字幕流时跳过；也检查当前媒体文件主名对应的外挂字幕（`.ass`、`.srt`、`.ssa`、`.vtt`，以及同名成对的`.sub`/`.idx`），允许主名后接语言等点号标签。同目录的其他媒体版本不互相阻断。媒体名含“中字”“简中”“中文字幕”或独立的“-c”标记也跳过；“无中字”“无简中”“无中文字幕”不触发名称规则。目录或媒体流读取失败会记录原因并跳过，下载前会再次检查；相同媒体路径的自动任务串行执行。手动搜索下载仍由管理员主动选择，本插件不会自动清理现有字幕文件。无结果时不自动提交云端生成。

新入库默认等待60秒，全新安装默认关闭，迁移继承原配置。补全计划任务默认没有触发时间，可在Emby计划任务中设置。媒体库的语言、匹配和跳过条件继续生效；番号同号不冒充原生视频哈希“完美匹配”。

下载使用原视频完整stem命名，按Emby规则附加语言及实际扩展名，例如：

```text
SSIS-157-c-无码破解.mp4
SSIS-157-c-无码破解.zh-CN.srt
```

语言标记以实际Emby版本的原生命名结果为准。字幕保存位置遵循媒体库设置。手动下载通过实际文件变化确认写入后刷新；自动补全在原生下载返回成功后刷新。二者只刷新对应视频，刷新时关闭再次字幕下载，不另排全目录扫描。

## 代理与字幕云

支持HTTP代理（含HTTPS CONNECT）和SOCKS5，可填写单独认证字段、局域网绕过和主机通配符。海南鸡、迅雷、字幕云、插件更新可分别选择路由；字幕云及局域网默认直连，本地文件访问仍使用文件系统。代理失败不自动转直连。配置保存后对新请求生效。设置页的测试按钮直接显示本次请求的实际路由（代理/直连）与往返延迟。

字幕云继续连接外部服务，保留STRM类型、音轨提示、路径映射、提交、任务查看和完成回报。配置、云操作、代理测试和更新仅管理员可用；自建设置接口仅返回密钥存在标记，空值保留，显式清除才删除。云端认证请求不跟随重定向，请填写服务的最终地址。

## 安装、迁移与更新

迁移版本3恢复旧海南鸡来源别名并保留已有媒体库设置；若旧配置没有显式选择海南鸡，来源会按库关闭。旧手动顺序映射到新的三来源顺序，缺少海南鸡时按默认优先级补齐。旧动态 PoolUrl 不会导入静态地址，避免将静态请求误发到动态 Worker；必须在正式静态池验收后填写 HTTPS 静态目录地址。版本标记避免重启后覆盖管理员后续修改，迁移备份及回滚遵循既有设置存储流程。独立旧公共池 Worker 仍可由运维人员手动回退，但本插件静态 provider 不会逐请求调用它。

生产部署使用 `tools/deploy_stage.py`：先确认指定Emby配置挂载，校验已验收DLL的SHA256，备份配置和SQLite一致性快照，再仅移出指定五个旧DLL并原子放入新DLL。脚本不重启Emby；安装后由管理员安排重启。不要将旧DLL继续保留在扫描的plugins目录。

“字幕助手：检查并安装更新”原生任务默认每24小时运行，只接受兼容当前宿主的正式版。下载、校验、备份、替换完成后仅通知待重启；不自动中断播放。设置页不再提供“检查更新”按钮，更新只由该计划任务执行。更新清单地址固定在代码中，不在设置页提供修改入口，默认：

```text
https://github.com/jzdxjk/subtitle-modal-web/releases/download/emby-subtitle-assistant-update/update.json
```

当前插件程序集版本为 `1.0.0.11`。正式更新仍由独立更新清单发布，更新清单指向不可变版本DLL。详见 `Updates/README.md`。

## 构建与验证

```powershell
dotnet test emby-unified-plugin.Tests/Emby.SubtitleAssistant.Tests.csproj -c Release
dotnet build emby-unified-plugin/Emby.SubtitleAssistant.csproj -c Release
```

编译基线为 netstandard2.1 和 SDK 4.8.11.0。`1.0.0.11` 的 Release 构建通过，223 个 .NET 测试、41 个 Python 辅助工具测试通过，1 个仅限 POSIX 的检查在 Windows 本机跳过。SHA-256 为 `2655a2d66c8df571451b18f27c842aee1a826b34c468c77c591e5f9a106b1b5c` 的同一 DLL 已在隔离的官方 Emby 4.10.2.0 宿主完成加载、五标签页、三个下载器、两个计划任务、管理员设置接口、未认证拒绝和静态海南鸡来源注册检查。此前静态池候选还已在 4.8.11.0、4.9.1.80、4.9.5.0、4.10.0.40 和 4.10.2.0 五个官方隔离宿主通过插件加载冒烟。实际部署必须使用正式 Release 中的同一个 SHA-256。
