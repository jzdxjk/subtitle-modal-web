# 字幕助手调用迅雷接口搜索排序规则

## 文档范围

本文描述字幕助手 **1.0.0.8** 当前的迅雷字幕搜索、候选处理、排序和下载行为，供其他工具理解或复现。本文只描述迅雷字幕来源内部的候选顺序；Emby 的来源顺序仍由媒体库设置和字幕助手的来源排序配置决定。

迅雷字幕搜索是 Emby 原生字幕提供程序流程的一部分，不是单独的字幕助手 HTTP 搜索端点。手动搜索与自动补全共用迅雷候选识别和排序规则，但手动展示数量限制不同于自动补全传入候选的数量限制。

1.0.0.8 中，海南鸡字幕不是独立字幕来源，而是通过迅雷库的标签查询返回的候选；普通迅雷查询仍会并行执行。早期将海南鸡字幕描述为独立下载器或独立字幕池的说明不适用于当前版本。

## 搜索请求

### 识别媒体编号

1. 从媒体文件名（不含扩展名）解析媒体编号。
2. 只有恰好识别出一个编号时才继续搜索；没有编号或存在多个不同编号时返回空结果。
3. 编号解析器会规范编号并生成等价查询形式。例如普通编号可能产生 `PREFIX-123` 与已配置的短前缀形式；日期编号、FC2、HEYZO、N 系列也各自生成对应形式。等价形式会去重。
4. 对每个查询形式分别执行普通搜索和海南鸡标签搜索，两组请求并发发出。

### 迅雷接口

- 方法：`GET`
- 地址：`https://api-shoulei-ssl.xunlei.com/oracle/subtitle?name=<URI 编码后的查询词>`
- 普通查询词：媒体编号查询形式，例如 `SNOS-338`。
- 海南鸡查询词：`海南鸡字幕 ` 加媒体编号查询形式，例如 `海南鸡字幕 SNOS-338`。
- 超时来自迅雷设置中的“请求超时”；1.0.0.8 默认值为 15 秒，可配置范围为 1–120 秒。
- 接口成功响应使用 `code` 和 `data` 字段；仅 `code == 0` 的 `data` 作为结果。非零业务码视为空结果。

若部分别名请求失败，仍使用其他成功请求返回的结果；海南鸡标签请求失败不会丢弃普通查询结果。若本次所有别名请求均发生传输或解析错误，则搜索返回空结果并记录警告，后续请求可以重试。取消操作会继续向上传播。

## 候选校验与字幕解析

候选按以下条件处理：

1. 只接受 `http` 或 `https` 下载地址，且 URL 不得包含嵌入式用户名或密码。
2. 候选编号优先取接口的 `code`；该字段为空时，使用 `name` 与 `extraname`（或 `extra_name`）识别编号。候选必须与当前媒体编号相同或等价。
3. 同一 URL 的接口行只预取一次字幕内容；预取最多并发 4 个 URL。
4. 可解析格式为 SRT、ASS、SSA；ZIP 中只处理这些格式的字幕条目。解析后的字幕必须含有可识别的字幕时间轴，否则不作为已解析文档。
5. 若字幕文档名还能解析出另一个作品编号，且该编号与媒体编号不匹配，则丢弃该文档。
6. 请求语言与候选实际语言都已知时，规范化后必须一致。支持中文、英语、日语、泰语和韩语的识别；若候选语言未知，或请求语言未知，则允许候选通过语言过滤。

### 语言来源

- 首选字幕文件名中的语言后缀，例如 `.zh-CN`、`.chi`、`.jpn`。
- 文件名没有可识别语言时，根据字幕正文判断语言。
- 解析出的语言仍未知时，使用迅雷接口的 `languages` 提示作为候选语言。
- 若字幕内容预取发生异常，但接口 `ext` 是支持格式，仍可使用接口的 `languages` 提示构造候选；接口语言缺失时按未知语言处理。若成功获取的内容无法解析成有效字幕文档，则该内容不会作为候选。

自动补全检查已有字幕文件时识别的外挂格式比迅雷候选解析范围更广：同媒体主名的 `.ass`、`.srt`、`.ssa`、`.vtt` 会阻止自动补全；`.sub` 与 `.idx` 只有同名成对时才阻止。不要把这两组格式规则混为一谈。

## 海南鸡字幕识别与展示

只有候选 `name` 文件名符合以下形式才识别为已上传的海南鸡字幕：

```text
{作品编号}.海南鸡字幕.{数字或小数}KB.{8位日期}.{srt|ass|ssa}
```

匹配不区分大小写；编号必须与当前媒体一致；若接口 `ext` 非空，它也必须与文件名扩展名一致。名称、编号、格式不匹配的结果按普通迅雷结果处理。

识别成功后，面向用户的候选名称改为：

```text
[海南鸡字幕] {作品编号}.{格式}
```

例如：

```text
[海南鸡字幕] SNOS-338.srt | 时长:01:57:19(字幕轴) | 大小:58.3 KB | 语言:中文
```

其中展示详情由字幕轴、接口时长、解析字节数和识别语言生成。已解析字幕优先使用时间轴结束时间作为时长；没有可用时间轴时使用接口的毫秒时长。缺少时长或大小时显示 `unknown`。大小以 1024 字节为 1 KB，保留 1 位小数。展示语言包括中文、英语、日语、泰语、韩语；其他或未知值显示“未知”。

**展示名只用于界面显示。** 下载载荷保留迅雷返回的原始文件名、主下载 URL、格式、语言、解析条目名和内容哈希；因此海南鸡短标签不会改变识别或下载目标。

## 去重与排序

### 去重

候选去重键为：

```text
(内容 SHA-256；若内容未解析则使用 URL) + 格式 + 规范化语言
```

重复候选合并为一个结果。第一个候选保留展示元数据和主 URL；其他重复项的 URL/路径作为备用项追加。由于海南鸡候选在去重前先被排到前面，同一内容同时出现在普通和海南鸡结果中时，若海南鸡结果满足语言优先条件，则由它保留首选展示名和主下载地址。

### 单个迅雷来源内的排序键

依次按以下规则排序：

1. **海南鸡优先标记**：只有候选符合固定海南鸡命名、作品编号匹配，且请求语言与候选语言规范化后明确相同，才置为优先。未知语言可以通过候选过滤，但不会因此获得海南鸡优先级。
2. **字幕时长接近媒体时长**：当媒体时长已知时，字幕轴时长与媒体时长的绝对差值越小越靠前；字幕时长未知的候选排在已知时长之后。当媒体时长未知时，跳过此项。
3. **文件大小**：大小已知的候选优先；大小都已知时，文件较大的排前。
4. **稳定顺序**：前述键相同时，保留候选进入列表时的稳定顺序。

海南鸡优先标记高于时长和大小，因此语言准确的海南鸡字幕可以排在时长或大小评分更高的普通字幕之前。来源之间的顺序不由这组键决定。

### 数量上限

- 手动搜索使用 `ThunderMaxResults` 限制显示数；有效范围为 1–10，默认值为 10。
- 自动补全搜索处于自动化执行上下文时，不应用这个手动展示数量截断；迅雷提供程序向后续自动化流程返回完整候选序列。此行为不表示会把所有候选都下载到媒体目录。

## 失败处理与缓存

- 单个候选的字幕预取失败时记录警告；若接口仍提供受支持的格式和语言提示，可继续构造候选。
- 下载时优先读取已缓存的已解析内容；否则尝试主 URL，再尝试校验过的备用 URL。下载内容必须与搜索时记录的内容哈希匹配；没有哈希时按记录的条目名选择。都不可用时下载失败，不改用任意其他文档。
- 相同搜索的并发调用会合并；成功结果的搜索缓存默认保留 60 秒，容量为 256 项。缓存键区分媒体路径、编号形式、语言、精确匹配/强制/听障标志、手动或自动化上下文及相关迅雷设置。搜索失败不作为成功结果长期缓存。
- 预取的文档元数据与内容缓存最长保留 24 小时；内容缓存总量上限为 128 MiB。

## 自动补全边界

自动补全规则只控制字幕助手的新入库和历史补全：

- 当前媒体有任何内嵌或已识别字幕流时跳过。
- 同目录有与当前媒体主名完全相同，或以“媒体主名 + 点号后缀”开头的外挂字幕时跳过；因此 `Movie.zh-CN.srt`、`Movie.forced.ass` 等会匹配。只检查当前目录，不递归；同目录其他版本的字幕不会阻断当前版本。
- 媒体文件名包含“中字”“简中”“中文字幕”时跳过；匹配前会排除“无中字”“无简中”“无中文字幕”。独立的 `-c` 标记也视为中文字幕标记，例如以 `-c` 结束或后接点号、空格、连字符的名称。
- 媒体目录或媒体流读取失败时记录原因并跳过，以免在状态不确定时下载重复字幕。
- 按媒体完整路径串行处理，并在真正下载前再次检查，避免同一媒体版本的并发任务重复下载。
- 手动搜索与用户选择下载不受这些自动补全跳过条件限制；插件不删除已有字幕。
