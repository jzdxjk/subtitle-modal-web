# 字幕助手 1.0.0.8

本次更新优化迅雷字幕搜索结果的展示，并完善字幕自动补全的已有字幕检查，减少不必要的重复下载。

## 字幕来源调整

- 独立的海南鸡字幕搜索器已移除，不再作为单独的搜索来源显示。
- 原海南鸡字幕库中的字幕已上传至迅雷字幕库。现在请通过“迅雷字幕”来源统一搜索；搜索命中海南鸡字幕时，会优先展示该结果。

## 1.0.0.8 更新内容

- **海南鸡字幕显示更清晰**：迅雷搜索命中海南鸡字幕时，使用“[海南鸡字幕] 作品编号.字幕格式”的名称展示，便于从搜索结果中辨认。
- **补充迅雷字幕说明**：迅雷字幕设置页说明海南鸡字幕已上传至迅雷字幕库，搜索命中时会优先展示。
- **改进自动补全判断**：新入库和历史补全都会检查当前媒体版本。检测到内嵌字幕或与媒体文件名匹配的外挂字幕时，跳过自动补全；同一文件夹中的其他媒体版本仍分别判断。
- **识别更多已有字幕线索**：支持识别媒体文件名中的中文字幕标记；“无中字”等否定标记不会误判为已有字幕。
- **保留手动选择**：用户仍可在手动搜索中选择并下载其他字幕；插件不会清理已有字幕文件。
